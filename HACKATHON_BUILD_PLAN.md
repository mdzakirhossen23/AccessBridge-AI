# Hackathon build plan

This file prevents pre-event work from being confused with hackathon-period development.

## Pre-hackathon baseline

- Responsive multilingual desktop-style interface
- Education, career, and digital-service guidance forms
- Live AI endpoint integration and local fallback
- Local saved plans and chat history
- Copy, download, read-aloud, and speech-input controls
- Accessibility settings and privacy notices

## Work to complete during the official event window

- Run structured usability sessions with target users
- Improve service-specific source grounding based on test feedback
- Add measurable before/after task-completion evidence
- Complete a documented keyboard and screen-reader audit
- Refine prompt safety and server-side rate limiting
- Record event-period commits with clear messages and test evidence

Do not backdate commits. The Git history must reflect the actual work date.
