# User-scenario testing record

Test date: 2026-10-28 (Asia/Dhaka)  
Environment: Production site, Live AI mode

## Scenario 1 — student developer

- User profile: 20-year-old HSC graduate preparing a student portfolio and hackathon evidence.
- Task: Create a beginner plan for a GitHub portfolio and honest hackathon evidence.
- Result: Passed.
- Evidence: The app returned a structured plan covering GitHub setup, portfolio work and evidence preparation.
- Controls verified: Copy, Save plan and Read aloud.

## Scenario 2 — Bengali-language digital service

- User profile: Bengali-language user seeking help with an online hackathon submission.
- Task: Explain the correct links, required files and submission steps.
- Result: Passed.
- Evidence: The app returned a Bengali plan covering the project description, source/GitHub link, demo material and README.
- Controls verified: Copy, Download and Save plan.

## Important evidence boundary

These were automated, realistic user scenarios, not signed human usability interviews. Human feedback must not be invented. A real-user sign-off remains pending until MD Zakir Hossain and one additional person use the production site and record their own observations.
